# デザインの写し

Design キャンバス「ikili.pro デザイン案」（https://claude.ai/artifact/BiganFnjujCyPVdmEdXHZL）の「C'案ブラッシュアップ」ページの 4 枚を、エージェントが読めるように写したものである。
見た目の正はキャンバスにあり、ここは参照用の写しである。キャンバスを直したら写しも取り直す。「検討」ページの案は不採用なので写していない。

| ファイル | キャンバスの題 | 大きさ |
| --- | --- | --- |
| `CBMain.dc.html` | C'案改（ライト初期） | 1440 × 4200 |
| `CBMainDark.dc.html` | C'案改（ダーク初期） | 1440 × 4200 |
| `CBMobile.dc.html` | C'案改 スマホ（ライト初期）。ファーストビューのみ | 390 × 844 |
| `CBMobileDark.dc.html` | C'案改 スマホ（ダーク初期）。ファーストビューのみ | 390 × 844 |

各ファイルは Design キャンバスの形式（`<x-dc>` の中のマークアップと `<helmet>` の `<style>`）で、キャンバスの外ではそのまま描画できない。スタイルとマークアップを読む資料として使う。
